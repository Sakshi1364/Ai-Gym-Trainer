# 🏋️ AI Gym Trainer

An AI-powered gym training assistant designed to help users improve their workout experience through intelligent feedback and exercise form analysis.

## 📌 Overview

**AI Gym Trainer** is an AI-based fitness project that aims to make workouts smarter by combining artificial intelligence, computer vision, and personalized feedback. It focuses on assisting users during exercise sessions by identifying potential form issues and providing useful workout guidance.

## ✨ Features

- 🏋️ **AI-Powered Fitness Assistance** — Intelligent support for workout sessions.
- 🎯 **Exercise Form Analysis** — Designed to help identify potential exercise form issues.
- 🤖 **Smart Feedback** — Provides feedback to help users improve their workout technique.
- 💬 **AI Fitness Coach** — Supports interactive fitness guidance.
- 📈 **Workout Improvement** — Helps users work toward better exercise habits and technique.

## 🛠️ Tech Stack

- **Programming Language:** Python
- **Computer Vision:** OpenCV and pose detection tools
- **AI Integration:** Groq API for AI-powered feedback
- **User Interface:** Streamlit
- **Version Control:** Git and GitHub

## 💻 Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Sakshi1364/Ai-Gym-Trainer.git
```

### 2. Navigate to the Project Directory

```bash
cd Ai-Gym-Trainer
```

### 3. Create a Virtual Environment

```bash
python -m venv .venv
```

### 4. Activate the Virtual Environment

**Windows Command Prompt:**

```cmd
.venv\Scripts\activate
```

**Windows PowerShell:**

```powershell
.\.venv\Scripts\Activate.ps1
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Configure Environment Variables

Create a `.env` file in the project root directory and add your Groq API key if required by your application.

```env
GROQ_API_KEY=your_groq_api_key
```

Replace `your_groq_api_key` with your actual API key. Never upload your API key or other secrets to GitHub.

### 7. Run the Application

If your Streamlit application entry point is `app.py`, run:

```bash
streamlit run app.py
```

If your main file has a different name, use that filename instead.
